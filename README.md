**呼风唤雨**是一支以「势力交错」和「标记机制」为核心的无名杀武将扩展。19 名武将分属魏、蜀、吴、群四大势力，其中多数拥有双势力或以登场势力起步、并可在游戏中变更势力；围绕「使命」设计的分岔成长路线让同一个武将在达成或错过使命后走向截然不同的技能组。标记既是资源也是燃料——势、勇、志、顾、仇、险、资……攒与耗之间就是整局的节奏。

全部技能使用 Async Content 写法，并配套选项级 AI、技能语音、动态技能描述与图鉴技能声明。

## 特性

### 使命：一个武将，两条路

关羽、姜维、诸葛亮各拥有一条使命线。使命未达成前，武将以登场势力作战；使命的**成功**与**失败**会给出完全不同的后续技能组，并往往连带切换势力：

- **狂关羽【单骑】**：杀死角色 → 升级【武圣·二级】、转为蜀势力、获得限定技【傲骨】；若先一步濒死 → 只获得体力上限与回复（错过成长）。
- **命姜维【继志】**：攒满 9 枚"志" → 获得【九伐】，走北伐路线；濒死 → 转为魏势力，获得【绝计】【困奋】。
- **命诸葛亮【三顾】**：场上"顾"标记攒到 3 枚 → 转为蜀势力并获得【天时】【火计】；持有"顾"的角色死亡 → 转入【尽瘁】【北伐】的失败线。

### 标记：资源与燃料

标记不只是计数，多数标记同时承担「进度条」与「货币」两种角色，中途还要被消耗掉：

- **势**（狂钟会）——造成或受到伤害积累，移去 2 枚从【决势】【擅兵】【镇骨】中购得一个技能，也是【睥睨】的弹药。
- **顾**（命诸葛亮）——其他角色持有的阵营标记，既决定使命成败，又为持有者提供三档光环，还能被【天时】【火计】移去换效果。
- **胆**（魄赵云）——2 / 6 / 10 / 14 枚依次解锁【龙胆】【绝境】【怀幼】【破围】，前期是成长曲线，后期是资源池。
- 其余还有 勇（狂吕布）、仇（魄马超）、险（魄邓艾）、资（商张飞）、财（商曹洪）、黄巾（命张角）、降（魄黄盖）等，完整列表见[标记一览](#标记一览)。

### 背水

多名武将拥有「背水」选项：主动付出体力上限或体力的代价，换取**同时结算全部选项**的强化版本。例如狂吕布【无双】背水后减少 1 点体力上限，本阶段【逞凶】可用次数 +1；魄马超【铁骑】背水后减少体力上限换取本阶段【杀】的次数上限 +1。代价与收益的取舍是这些武将的主要决策点。

### 转换技与动态描述

【八卦】（命诸葛亮）、【应天】（命张角）、【龙胆】等转换技按阴阳两面轮流生效，技能面板显示当前面与已记录状态；【武圣】升级为二级、【踏浪】升级为二级后，技能描述由 `dynamicTranslates.js` 随状态实时切换，无需额外记忆版本差异。

### 立绘、语音与皮肤

- 每名武将配独立立绘（`image/`），技能与阵亡语音取自官方素材（武将自带 `dieAudios`，技能自带 `audio`）。
- 势力变更会同步替换立绘：狂钟会（魏→群）、商张飞（群→蜀）、命诸葛亮（使命成功/失败切换 1 / 2 号皮肤）、狂关羽、命张角、命姜维。
- 专属卡牌【破釜沉舟】附带男女声卡牌使用音效。

### AI 与图鉴

- 主要技能均实现选项级 AI：按局势计算弃牌数与目标（【突袭】逐距离圈累加收益）、按身份决定是否相助（【三顾】）、按手牌与体力挑选技能（【筹伐】）、背水取舍（【决势】【擅兵】）等。
- 运行时获得的技能（【尽瘁】【北伐】【龙胆】等）通过 `derivation` 声明，可在图鉴中正常查看。
- 标记技能带 `mark` / `marktext` 与 `intro`，武将牌上直接显示当前标记数量与内容。

## 安装

### 从 Release 安装（推荐）

1. 在 [Releases](https://github.com/shibaiderman096/noname-extension-hufenghuanyu/releases) 下载最新的 `hufenghuanyu-vX.Y.Z.zip`（**无需解压**）。
2. 打开无名杀 →「扩展」→「导入扩展」，选择该压缩包。
3. 在扩展列表中找到「呼风唤雨」并启用；创建房间时勾选本扩展或直接选用其中武将。
4. 若武将未出现在武将列表，重启游戏后再试。

### 从源码安装（开发者）

```text
把 呼风唤雨/ 整个目录放入：
<无名杀目录>/resources/app/extension/呼风唤雨/
```

目录名需保持为 `呼风唤雨`（扩展内的立绘、语音资源均以 `ext:呼风唤雨/...` 路径引用）。放入后重启游戏，在扩展设置中启用即可。

### 兼容性

- 需要无名杀（libnoname）**1.10 或以上**，技能全部采用 Async Content 写法。
- 所有技能名带 `hfhy_` 前缀，卡牌名为 `hfhy_pofuchenzhou`，与官方武将不冲突；本扩展中另有狂/命/魄/商/勇前缀的同名武将（如狂关羽、命诸葛亮），与官方同名武将互为独立角色，可按需同时启用。

## 分系详解

### 狂系（5 名）

高收益伴随高代价：以体力上限、护甲或手牌为燃料换取爆发。

#### 狂董卓（群 · 男 · 3/4 · 1 护甲）

| 技能 | 分类 | 效果摘要 |
|---|---|---|
| 狂战 | 锁定技 | 造成或受到伤害后，若体力上限小于 8，+1 点体力上限并摸一张牌。 |
| 突袭 | 出牌阶段限一次 | 弃置 X 张牌，视为对所有与你距离小于 X 的角色使用一张不计入次数限制的【杀】。 |
| 破极 | 觉醒技·锁定技 | 造成伤害时若体力上限 ≥ 8，将体力上限调整为 4 并获得 1 点护甲，获得【蛮战】与【崩坏】，然后视为使用一张【南蛮入侵】。 |
| 蛮战 | 触发技（觉醒后） | 造成伤害时，若伤害来源体力上限大于目标，可减 1 点体力上限令此伤害 +1。 |

#### 狂钟会（魏 → 群 · 男 · 3/3 · 1 护甲）

| 技能 | 分类 | 效果摘要 |
|---|---|---|
| 枭据 | 锁定技·觉醒技 | 登场势力为魏；回合结束时若体力上限 ≥ 5，势力改为群并获得【睥睨】，然后选择回复 1 点体力 / 摸两张牌 / 获得 1 枚"势"。 |
| 筹伐 | 魏势力技 | 游戏开始时获得 2 枚"势"；造成或受到伤害后再得 1 枚。准备阶段或弃牌阶段可移去 2 枚"势"，从【决势】【擅兵】【镇骨】中选择一个获得，并 +1 点体力上限。 |
| 决势 | 出牌阶段限一次 | 弃 1 张牌视为使用无次数限制的【杀】，或弃 2 张牌视为使用【无中生有】。背水：失去 1 点体力并获得 1 枚"势"。 |
| 擅兵 | 触发技 | 你使用的【杀】不可被响应；造成伤害时可弃一张黑色牌令伤害 +1，或弃一张红色牌获得其区域内一张牌。背水：同上。 |
| 镇骨 | 触发技 | 受到伤害时可弃一张牌，将手牌摸至体力上限；若以此法获得的牌少于 2 张，获得 1 枚"势"。 |
| 睥睨 | 群势力技·出牌阶段限一次 | 失去 1 点体力或移去 1 枚"势"，视为使用一张普通锦囊牌。 |

#### 狂关羽（魏 / 蜀 · 男 · 4/4）

| 技能 | 分类 | 效果摘要 |
|---|---|---|
| 单骑 | 使命技 | 登场势力为魏。摸牌阶段开始时选择一名其他角色，获得其区域内一张牌，或对其使用【杀】无距离限制。背水：减 1 点体力上限。成功：杀死一名角色后升级【武圣·二级】、势力变更为蜀并获得【傲骨】。失败：进入濒死时 +1 点体力上限并回复 1 点体力。 |
| 斩将 | 魏势力技 | 出牌阶段开始时展示牌堆顶一张牌：基本牌则获得并回复 1 点体力；锦囊牌则从弃牌堆获得两张基本牌；装备牌则此阶段你使用【杀】造成的伤害 +1。 |
| 武圣 | 每轮限两次 | 将一张手牌当【杀】使用或打出：基本牌转换不计入次数限制、锦囊牌转换摸一张牌、装备牌转换不可被响应。 |
| 武圣·二级 | 使命成功后升级 | 同上；另加：其他角色因该【杀】受到伤害时弃置一张手牌。 |
| 傲骨 | 蜀势力技·限定技（成功后获得） | 展示所有手牌并与一名其他角色拼点：赢则获得其一个区域内的所有牌；未赢则从弃牌堆获得每种牌型各一张。 |

#### 狂吕布（群 · 男 · 4/5）

| 技能 | 分类 | 效果摘要 |
|---|---|---|
| 无双 | 锁定技 | 使用【杀】/【决斗】时选择：额外指定 X 名攻击范围内的其他角色为目标，或令此【杀】需 X 张【闪】抵消（【决斗】每次需 X 张【杀】）。背水：减 1 点体力上限，此阶段【逞凶】次数 +1。每回合限一次：若对方未使用或打出【杀】或【闪】，此牌对其伤害 +1。X 为本轮发动次数。 |
| 逞凶 | 出牌阶段限一次 | 将一张基本牌 / 锦囊牌视为【杀】/【决斗】使用；你使用【杀】/【决斗】造成伤害时获得 1 枚"勇"。 |
| 恃勇 | 出牌阶段 | "勇"不少于 3 枚时可移去所有"勇"，选择 +1 点体力上限 / 获得 1 点护甲 / 摸两张牌。 |

#### 狂黄忠（蜀 · 男 · 4/4）

| 技能 | 分类 | 效果摘要 |
|---|---|---|
| 暮雄 | 锁定技 | 游戏的前两个准备阶段 +1 点体力上限，之后的准备阶段 -1 点体力上限；攻击距离视为 X。使用【杀】指定目标时：若其攻击距离小于 X，此【杀】不可响应；若其体力值不小于你的攻击距离，此伤害 +X；若其因此进入濒死，你减 1 点体力上限，且此阶段你使用牌不能选择其他角色为目标。X 为体力上限的一半（向下取整）。 |
| 定军 | 锁定技 | 游戏开始时废除武器栏；出牌阶段可重铸武器牌；杀死一名角色后执行一个额外回合。 |

### 商系（3 名）

以「储备牌」为核心：把牌移到武将牌上囤积，再兑换成需要的资源。

#### 商麋竺（蜀 · 男 · 4/4）

| 技能 | 分类 | 效果摘要 |
|---|---|---|
| 商略 | 准备阶段 | 选择跳过摸牌 / 出牌 / 弃牌阶段之一：跳摸牌 → 摸体力值张牌并失去 1 点体力；跳出牌 → 视为对攻击范围内一名其他角色使用【杀】且本回合手牌上限 +X；跳弃牌 → 本回合不能对其他角色使用牌。 |
| 敛财 | 触发技 | 回合外失去手牌后，若当前手牌数不小于体力值，摸一张牌。 |
| 却敌 | 触发技 | 成为其他角色使用牌的目标时，可交给其 X 张牌并取消此目标。X 为已损失的体力值（至少为 1）。 |

#### 商张飞（群 / 蜀 · 男 · 3/3）

| 技能 | 分类 | 效果摘要 |
|---|---|---|
| 集资 | 储备技 | 登场势力为群。游戏开始时可把牌堆顶两张牌置于武将牌上，称为「资」；回合外获得牌时可置于其上；需要使用或打出一张基本牌时，可移去一张「资」视为使用或打出。 |
| 贾策 | 群势力技 | 其他角色摸牌阶段开始时，可交给其一张「资」，令其对你指定的一名角色使用【杀】；若其未使用，你摸两张牌。 |
| 归汉 | 限定技 | 准备阶段若「资」不少于 3 张，势力变更为蜀并获得【咆哮】。 |
| 万敌 | 蜀势力技 | 你的【杀】造成伤害时，可移去一张「资」令此伤害 +1。 |

#### 商曹洪（魏 · 男 · 3/3）

| 技能 | 分类 | 效果摘要 |
|---|---|---|
| 积财 | 储备技 | 游戏开始时将牌堆顶 13 张牌置于武将牌上，称为"财"；摸牌阶段开始时可在"财"与手牌之间任意转移。 |
| 通商 | 出牌阶段 | 移去至多三张"财"，按移去数量从牌堆获得一张基本牌 / 锦囊牌 / 装备牌。 |
| 济困 | 出牌阶段限一次 | 将一张牌交给其他角色；若为装备牌，该角色可使用之并回复 1 点体力。 |

### 命系（4 名）

使命与阵营变更的主场：同一个武将的两条成长路线，往往连带势力改动。

#### 命诸葛亮（群 → 蜀 · 男 · 3/5）

## 常见问题

**Q：启用扩展后武将列表里找不到这些武将？**
确认扩展已在「扩展」界面启用，并重启游戏；部分模式（如身份局）需要在房间设置中勾选该扩展包。

**Q：使命技没有成功，直接走了失败线？**
这是设计内的分支。使命失败有明确触发条件（例如【三顾】中持有"顾"标记的角色死亡、【单骑】/【继志】率先进入濒死），走向不同技能组属于正常结算。

**Q：技能没有声音？**
语音取自官方素材，需游戏内存在对应语音资源；缺失的语音会被静默跳过，不影响结算，也不影响技能可用性。

**Q：会和其他扩展冲突吗？**
本扩展所有技能名带 `hfhy_` 前缀、卡牌为 `hfhy_pofuchenzhou`，与官方及其他扩展的标识不重叠；同名的官方武将（如官方诸葛亮）与本扩展的「命诸葛亮」互为独立角色，可按需同时启用。若与其他扩展争夺同名技能标识，可在房间设置中只启用本扩展。

**Q：完整技能描述在哪里看？**
游戏内武将详情 / 图鉴的文案即完整描述；离线查阅见 [武将技能总览.md](武将技能总览.md)，其中按技能分类列出全部逐字文案与标记汇总。

## 开发与发版

一键发版（自动改版本号 → 写 CHANGELOG → 提交打 tag → 打包 → 推送 → 创建 Release 并上传资产）：

```bash
./release.sh <版本号> <提交信息> [更新日志文件]
# 例：./release.sh 1.5.4 "fix: 修正某技能结算" /tmp/v1.5.4.md
```

- 更新日志文件为可选的 markdown 正文（不含版本标题，脚本自动生成），会被写入 `CHANGELOG.md` 顶部并附进 Release 正文；
- 脚本随后调用 `node _gen_changelog.cjs` 重新生成游戏内 `changelog.js`；
- 产物命名为 `hufenghuanyu-v<版本号>.zip`，可直接通过无名杀「导入扩展」安装。

手动只更新游戏内更新日志：

```bash
node _gen_changelog.cjs
```

发版前请同步确认 `info.json` 与 `extension.js` 中的版本号、以及 `CHANGELOG.md` 的内容一致。
