# 呼风唤雨

> 无名杀武将扩展 · 22 名武将 + 2 张专属卡牌 · 势力交错 × 标记机制 × 使命双分支

| 项目 | 说明 |
|---|---|
| 当前版本 | **v1.8.5** |
| 运行环境 | [无名杀 / libnoname](https://github.com/libnoname/noname) 1.10+ |
| 武将数量 | 22 名（狂 / 商 / 命 / 魄 / 勇 五系） |
| 专属卡牌 | 2 张（破釜沉舟、血影挽歌） |
| 作者 | 无名玩家（[shibaiderman096](https://github.com/shibaiderman096)） |
| 贡献者 | [shibaiderman096](https://github.com/shibaiderman096) · ZCode AI 助手（技能实现与工程化） |
| 开源协议 | [GPL-3.0](LICENSE) |
| 仓库 | <https://github.com/shibaiderman096/noname-extension-hufenghuanyu> |

以「势力交错」和「标记机制」为核心的无名杀武将扩展：使命技带来一条武将两条成长路线，标记既是进度条也是可消耗的燃料。全部技能采用 Async Content 写法，配套选项级 AI、技能语音、动态描述与图鉴声明。

## 安装

在 [Releases](https://github.com/shibaiderman096/noname-extension-hufenghuanyu/releases) 下载最新的 `hufenghuanyu-vX.Y.Z.zip`（无需解压），无名杀「扩展」页导入即可。开发者可将本目录整个放入 `<无名杀目录>/resources/app/extension/呼风唤雨/`。

## 开发

```text
呼风唤雨/
├── extension.js      入口：武将定义、文案、游戏内更新日志面板
├── skill.js          全部技能实现（Async Content + AI + 语音）
├── card.js           专属卡牌与装备技能
├── CHANGELOG.md      版本记录（唯一来源）
├── 武将技能总览.md    全部技能的逐字文案
└── release.sh        一键发版：./release.sh <版本号> <提交信息> [更新日志文件]
```

约定：技能标识 `hfhy_` 前缀；运行时获得的技能用 `derivation` 声明以便图鉴显示；发版脚本自动同步三处版本号并生成 Release。
