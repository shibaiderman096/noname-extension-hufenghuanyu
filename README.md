# 呼风唤雨

**扩展名称**：呼风唤雨
**作者**：无名玩家
**版本**：1.3
**类型**：武将扩展（16名武将）

---

## 扩展简介

呼风唤雨是一支以**势力交错**和**标记机制**为核心的武将扩展，角色涵盖魏、蜀、吴、群四大势力。多数角色拥有双势力或动态势力变换，围绕"使命/觉醒"设计了分岔的成长路线：同一个武将，达成或错过使命，会走向截然不同的技能组。标记既是资源也是燃料——势、勇、志、顾、仇、险，攒与耗之间就是整局的节奏。

适用于无名杀（libnoname 1.10+），技能全部采用 Async Content 写法。

## 核心机制

- **使命双分支**：关羽、姜维、诸葛亮的使命技成功与失败走向不同的技能组，阵营随使命结果切换
- **标记系统**：势、勇、志、顾、仇、险、资等标记，多数标记既是资源又是燃料（天时/火计消耗顾，北伐背水烧上限）
- **背水机制**：付出体力/上限等代价，换取所有选项的强化结算
- **转换技**：八卦、应天等阴阳状态切换，记录制与状态制衡
- **动态翻译**：技能描述随状态动态切换（武圣等级、顾标记数、已记录牌名等）

## 安装

1. 下载 Release 中的 `hufenghuanyu-v1.3.zip`
2. 无名杀菜单：扩展 → 导入扩展，选择该压缩包
3. 重启游戏后在武将列表启用
