# 更新日志 - 2026年6月16日（补充）

## 新增技能

### 【暮雄】`hfhy_muxiong`
- 锁定技。游戏的前两个准备阶段增加1点体力上限，之后扣减体力上限
- 攻击距离视为 X（X 为体力上限的一半向下取整，最小为 1）
- 使用【杀】指定目标时：若目标攻击距离 < X，此【杀】不可响应；若目标体力值 ≥ X，伤害 +X
- 若目标因此进入濒死，减少 1 点体力上限，且此阶段不能对其他角色使用牌

### 【定军】`hfhy_dingjun`
- 锁定技。游戏开始时废除武器栏
- 出牌阶段可重铸武器牌（手牌区或装备区）
- 杀死一名角色后，执行一个额外出牌阶段

### 【血仇】`hfhy_xuechou`
- 蜀势力技。准备阶段令一名角色获得"仇"标记
- 对拥有"仇"标记的角色使用牌无距离限制
- 可移去"仇"标记令目标受到的伤害 +1

### 【羌助】`hfhy_qiangzhu`
- 群势力技。出牌阶段限一次，令一名群势力角色交给你一张牌
- 本回合内使用与该牌同名的牌无次数限制

### 【铁骑】`hfhy_tieji`
- 使用【杀】指定目标时，可令其本回合非锁定技失效
- 选项一：获得其一张手牌
- 选项二：令其不能使用或打出红色手牌
- 背水：失去 1 点体力，此阶段使用【杀】次数 +1

## 技能优化

### 【暮雄】`hfhy_muxiong`
- 修复加伤不生效问题：改用 `damageBegin1` 直接判断目标体力条件
- 伤害条件从 `<` 改为 `≥`（不小于）
- 移除 `charlotte`（持恒技标签）
- 濒死惩罚新增：此阶段不能对其他角色使用牌

### 【定军】`hfhy_dingjun`
- 修复 `gameStart` 不触发问题：改用 `global: "gameStart"` 事件
- 废除武器栏改为直接操作底层存储 `disabledSlots`
- 击杀奖励从"加体力上限 + 摸牌"改为"执行额外回合"

### 【血仇】`hfhy_xuechou`
- 修复 `content` 中 `target` 为 `undefined` 导致报错的问题
- 将目标选择从 `cost` 移到 `content`，解决锁定技弹窗不显示问题
- 添加标记显示（`mark: true`）

### 【马术】`hfhy_mashu`
- 距离减成从"向上取整"改为"向下取整"
- 距离计算包含自己

### 【踏浪】`hfhy_talang`
- 修复一级时错误享有二级效果的问题
- 所有 `getStorage` 添加默认值 `false`

## 系统规范

- 统一势力判断方式：在 `filter` 中显式判断，`groupSkill` 仅用于标记
- 禁止随意添加 `charlotte: true`（持恒技标签），避免技能免疫封印
- 背水机制统一：先执行所有普通选项，再执行背水代价
- 触发时机选择：`global:` 事件比 `player:` 事件更可靠，避免技能加载时序问题
